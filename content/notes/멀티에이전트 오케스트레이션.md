# 멀티에이전트 오케스트레이션

> 에이전트의 자유도를 **프롬프트가 아니라 구조로** 제한한다.

## [[AI Org Simulation]] — 검증 게이트

| 장치 | 역할 |
|---|---|
| `modules/human_confirm.py` | 사람 확인을 강제하는 체크포인트 |
| `pipeline/token_limit_verify.py` | 토큰 초과 사전 검증 — 대화가 길어지며 비용이 터지는 걸 방지 |
| `pipeline/validation_runner.py` | 단계별 산출물 검증 |
| `modules/coverage_check.py` | 누락 점검 |
| `pipeline/section_splitter.py` | PRD를 섹션으로 쪼개 한 번에 다 넣지 않음 |

**"잘 해줘"라고 부탁하는 대신 통과해야 할 관문을 코드로 만들었다.**

판단도 정량화했다 — `column_selection_draft` → `column_weighting_final` → `employee_team_ranking`. LLM의 인상 평가가 아니라 **가중 점수로 팀 조합을 정한다.**

## [[US Vibe]] — 실행 가능한 운영 계약

에이전트에게 주는 지시를 "정책"이 아니라 **executable operating contracts** — 지켰는지 **판정 가능한 형태**로 다시 썼다.

4일짜리 MVP인데 PR #2~#6이 전부 문서다. 코드보다 먼저 고정한 것:
완료 트리거 / 4인 고정 오너십 차터 / 백엔드 단독 MVP 시나리오 / **비용·실현가능성 통제를 반영한 아키텍처**

## [[실은 silen]] — 여러 AI가 번갈아 일하는 저장소

*"이 저장소는 여러 AI(Claude · Codex · Gemini · Cursor)가 번갈아 작업한다."*

*"추적 안 된 파일은 다음 세션·에이전트에서 보이지 않는다."*

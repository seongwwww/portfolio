# AI 결과물을 사람이 검토하게 만들기

> AI가 무언가를 바꾸는 도구에서 가장 중요한 건 **되돌릴 수 있는가**다.

## [[Nextify]] — 세션이라는 중간 상태

CLI가 AI로 코드를 변환하되 **파일에 바로 덮어쓰지 않는다.**

```
CLI 변환 → .ai-migration/.../session.json → VS Code 확장이 읽음
          → Explorer에 트리·diff·경로 복사 패널 → 사람이 승인
```

### 되돌릴 수 있는 단위로 쪼갰다

step1(환경) → step2(레이아웃·프로바이더) → step3(라우팅) → step4(스타일·에셋) → step5(브라우저 API)

한 번에 전부 바꾸면 어디서 깨졌는지 알 수 없다. 단계마다 diff를 확인하고 넘어가면 실패 지점이 좁혀진다.

## [[AI Org Simulation]] — human_confirm 체크포인트

`modules/human_confirm.py` + `local_inputs/human_confirm_decision_prd_001.json`

파이프라인 중간에 **사람의 확인을 강제**한다. 에이전트가 끝까지 혼자 달리지 못하게 끊어 놓았다.

## [[정책핏 인천]] — 결정은 사람이

발표 슬라이드에 명시: **LLM은 원문에서 필드를 추출하고 후보를 제안, 판정은 규칙, 결정은 사람.**

LLM 금지 목록을 화면에 노출했다 — 출처 없는 사실 보완 / 정합성 점수 직접 생성 / 사업폐지·예산삭감 자동결정.

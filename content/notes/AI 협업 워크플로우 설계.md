# AI 협업 워크플로우 설계

> AI로 개발하는 게 아니라, **AI와 일하는 방식 자체를 설계**한다.

## [[실은 silen]] — 규칙을 컨텍스트 예산으로 쪼갰다

`CLAUDE.md` 머리말:

> **"이 파일은 항상 적용되는 핵심 원칙만 담는다. 세부 규칙은 `.claude/rules/`, 절차는 Skill, 강제 검사는 Hook으로 분리한다. 200줄 이하 유지."**

| 위치 | 담는 것 |
|---|---|
| `CLAUDE.md` | 항상 로드되는 불변 원칙 (제품·프라이버시·엔지니어링) |
| `.claude/rules/` × 7 | 도메인별 세부 규칙 — frontend · backend · database · privacy · ai-evals · testing · git |
| Skill | 절차 |
| Hook | 강제 검사 |
| `AGENTS.md` | 모든 에이전트의 공통 진입점 |
| `PROJECT_STATE.md` · `progress.md` | 세션 연속성 |

**1주일에 커밋 287개**가 나온 방식이 여기 있다.

설계서를 먼저 쓰고 구현했다 — `docs/superpowers/specs/` 와 `plans/`.

## [[정책핏 인천]] — 36시간에 5개 트랙

`CLAUDE.md` · `AGENTS.md`를 루트에 두고, 저장소 구조 자체를 작업 순서로 만들었다.

```
01_기준자료 → 02_조사자료 → 03_제품설계 → 04_핸드오프 → 05_발표자료 → 06_앱
```

**결정 43건을 로그로 남겼다** (`01_결정로그.md`, 101KB). 번복도 기록했다 — 그래프 DB 기각(D-009) → Neo4j 채택(D-010), 디자인 외주 발주(D-039) → 직접 구현(D-040).

## [[US Vibe]]

`.ai/` · `.claude/` · `agents/` — 에이전트 운영 정책을 문서로 먼저 고정.

## 왜 이게 차별점인가

대부분은 AI를 **도구로 쓴다.** 프롬프트를 넣고 결과를 받는다.
여기서 한 단계 더 간 건 — **AI가 지켜야 할 규칙, 끊길 때의 인계 절차, 검증 게이트를 미리 설계**한 것이다.

혼자 1주일에 287커밋, 셋이 36시간에 5개 트랙이 나온 이유다.

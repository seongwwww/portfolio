## 💡 아이디어

이벤트 준비를 한곳에서. **설문에 답하면 맞춤 준비 패키지를 만들어 준다.**

## 🔍 도출 과정

첫 커밋이 `feat: 폴더 구조 생성 (#1)`이다. **구조를 잡는 것부터 시작**해서 주요 화면과 API 연동을 대부분 담당했다.

9일짜리 대회 프로젝트치고 기술 선택이 정돈돼 있다 — React Hook Form + Zod로 폼 검증, TanStack Query로 서버 상태, Zustand로 클라이언트 상태를 분리하고 `MobileScreen` 레이아웃으로 모바일 우선 설계.
